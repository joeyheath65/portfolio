# Welcome to my Digital Portfolio

## Introduction
This is my personal portfolio site — built with Next.js, React, TypeScript, and Tailwind CSS, deployed serverless on Vercel. It showcases my work as a network engineer and full-stack developer, including Lawn Dart! Systems and its flagship product, Slot'd.

## Getting Started

First, clone the project from my public repository:

```bash
git clone https://github.com/joeyheath65/portfolio.git
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.


## Usage
This is my live digital portfolio web application which is running serverless in Vercel. You can access the page at https://joeheath.com.
